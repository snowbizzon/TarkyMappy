Привет! Хочу поделиться проектом **TarkyMappy** — прозрачной клик-сквозь
миникартой для Escape from Tarkov под Windows 10/11.

Работает офлайн: все карты, выходы, квесты, лут и опасности зашиты в exe.
Приложение не читает память игры, не внедряется в процесс и не перехватывает
трафик. Оно смотрит только **имя файла скриншота**, который EFT сохраняет по
PrtSc, и по координатам из имени определяет карту, позицию и направление
взгляда.

**Что умеет**
- 10 карт, многоэтажные подложки (Customs, Factory, Ground Zero, Interchange,
  Labs, Lighthouse, Reserve, Shoreline, Streets of Tarkov, Woods).
- Выходы и транзиты: PMC / Scav / общие, с этажами.
- Опасности: минные поля, снайперские зоны, клейморы/ловушки.
- Quest Helper: отслеживание квестов вручную и из логов EFT, цели, ключи,
  двери и ссылки на wiki.
- Farm Helper: кластеры лута, маршрут от текущей позиции, выбор дальнего выхода.
- Помощник цен: топ барахолки по ₽/слот, вкладки PvP/PvE, обновление без
  пересборки.
- RU/EN интерфейс, настройки в F9, глобальные хоткеи.

**Важно: нужен первый скриншот**
После спавна в рейде нажмите **PrtSc**. Без первого скриншота приложение не
знает позицию и не может центрировать карту. Если папка скриншотов
нестандартная — F9 → Browse → выбрать папку → Apply.

**Хоткеи**
F2 — цены, F3 — фарм, F4 — квесты, F5/F6 — зум, F7 — скрыть/показать,
F8 — выход, F9 — настройки, F10 — смена карты, PgUp/PgDn — этажи,
? в F9 — справка.

**Скриншоты**
В репозитории лежат 5 превью карты Маяк с разными слоями (выходы, опасности,
квесты, фарм, всё вместе). При публикации прикрепите их к посту или дайте
ссылку на папку `docs/screenshots`.

**Скачать / собрать**
GitHub: https://github.com/<your-account>/TarkyGo
Releases: https://github.com/<your-account>/TarkyGo/releases

Из исходников: `build_ru.bat` или `build_en.bat` — проверят Go, прогонят тесты
и соберут `dist\TarkyMappy.exe`. Рядом должна лежать папка `prices\`.

**Про Маяк**
Маяк **не проверен в живом рейде**: карта пока закрыта для меня по игровой
прогрессии. Превью и данные Маяка сгенерированы из встроенных данных, а не
сняты с игры. Пожалуйста, отнеситесь к выравниванию карты, выходам, опасностям
и квестам Маяка как к непроверенным.

**Лицензия**

**TarkyMappy — offline minimap overlay for Escape from Tarkov** 🗺️

Transparent click-through overlay for Windows 10/11. No game memory access, no
injection, no network during play. It reads the **screenshot file name** written
by EFT and derives your position and map.

**Features**
• 10 maps and multi-floor views
• PMC / Scav / shared extracts and transits
• minefields, sniper zones, claymores
• Quest Helper: quests, objectives, keys, doors, wiki
• Farm Helper: loot route and exit picker
• flea prices by slot (PvP / PvE)
• RU / EN UI

**First launch**
Enter a raid and press **PrtSc** once — without the first screenshot the overlay
has no position. Set a non-standard folder in F9 → Browse → Apply.

**Hotkeys:** F2 prices · F3 farm · F4 quests · F5/F6 zoom · F7 hide ·
F8 quit · F9 settings · F10 map · PgUp/PgDn floors · ? help

**Lighthouse is NOT verified in a live raid** — it is locked by game
progression; the previews are rendered from data, not gameplay.
