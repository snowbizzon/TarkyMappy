# TarkyMappy — подробная инструкция (RU)

TarkyMappy — прозрачный клик-сквозь мини-оверлей для **Escape from Tarkov**
(Windows 10/11, Go + Ebitengine). Он читает имя последнего игрового скриншота,
определяет карту по координатам, рисует карту вокруг игрока и показывает
выходы, опасности, квесты и маршрут фарма.

> **Главное:** для начала работы нужен **первый скриншот в рейде**.
> Без него приложение не знает вашу позицию и не может центрировать карту.
> Нажмите `PrtSc` после спавна — этого достаточно.

---

## 1. Что нужно

- Windows 10 или 11 (64-bit).
- Escape from Tarkov в режиме **Borderless** или **Windowed** (в полноэкранном
  эксклюзивном режиме прозрачное окно может не отображаться).
- Папка скриншотов EFT:
  `Documents\Escape from Tarkov\Screenshots`
  (по умолчанию; при перенаправлении Documents в OneDrive приложение ищет и
  `OneDrive\Documents\Escape from Tarkov\Screenshots`).
- Для обновления цен: Python 3.8+ (только стандартная библиотека).
- Для сборки из исходников: Go 1.27+.

Приложение не требует прав администратора.

---

## 2. Быстрый старт

1. Распакуйте архив или папку `dist` целиком. Рядом с `TarkyMappy.exe`
   должна лежать папка `prices`.
2. Запустите `TarkyMappy.exe`.
3. Зайдите в рейд и сделайте **один скриншот** (`PrtSc`).
4. Оверлей появится и отцентрируется на вашей позиции.
5. Если папка скриншотов нестандартная: `F9` → **Browse…** → выберите папку
   `Screenshots` → **Apply**.
6. Дальше просто играйте. Новые скриншоты обновляют позицию.

Первый запуск создаёт конфиг:
`%AppData%\TarkyMappy\config.json`.
Лог пишется рядом с exe: `tarkymappy.log`.

## 3. Горячие клавиши

Хоткеи работают глобально, фокус окну не нужен.

| Клавиша | Действие |
|---|---|
| `F2` | Панель цен барахолки: топ предметов по цене за слот, вкладки PvP/PvE |
| `F3` | Помощник фарма: категории лута, точки маршрута, выбор выхода |
| `F4` | Помощник квестов: отслеживаемые квесты, цели, ключи, wiki |
| `F5` | Приблизить карту |
| `F6` | Отдалить карту |
| `F7` | Скрыть / показать оверлей |
| `F8` | Выход из приложения |
| `F9` | Настройки |
| `F10` | Следующая карта (ручной выбор) |
| `PageUp` / `PageDown` | Этаж выше / ниже (многоэтажные карты) |
| `?` в F9 | Панель FAQ |

Пока открыта панель (`F2`, `F3`, `F4`, `F9`, FAQ), клики по окну работают.
После закрытия окно снова становится клик-сквозным.

## 4. Первый скриншот и определение карты

EFT сохраняет скриншоты с координатами и кватернионом в имени файла, например:

```
2026-08-30[17-30]_388.36, 2.64, -114.48_0.00027, 0.98771, -0.00171, 0.15626_8.60 (0).png
```

TarkyMappy разбирает **только имя файла**:

- `X, Y, Z` — позиция игрока;
- кватернион — поворот взгляда (`RotY`);
- по `X,Z` определяется карта;
- по `Y` выбирается этаж.

Содержимое PNG не читается и не анализируется.

### Почему без первого скриншота не работает

До первого скриншота у приложения нет координат. Оно может помнить последнюю
карту (`lastMap`) и даже показать её, но точка игрока появится только после
первого скриншота. Поэтому:

1. Зайдите в рейд.
2. Нажмите `PrtSc`.
3. Дождитесь, пока оверлей обновится.

Если скриншоты не появляются, проверьте настройки EFT: игра должна сохранять
скриншоты в папку `Screenshots`. Сторонние оверлеи (Steam, NVIDIA, Discord)
могут перехватывать `PrtSc` — отключите их или используйте игровую кнопку.

### Автоопределение и ручной выбор

- Автоопределение идёт по прямоугольникам карт (`data/maps.json`).
- У Customs и Reserve прямоугольники частично пересекаются. Без истории
  рейдов возможна ошибка — используйте `F10` или ручной выбор в `F9`.
- `F10` переключает карту и запоминает выбор (`Manual pick`).
- Чтобы вернуться к автоопределению, снимите ручной выбор в `F9`.
- Если указана папка логов EFT, карта может определиться по логу ещё до
  первого скриншота (удобно для оффлайн/PvE).

## 5. Что видно на карте

> **Маяк не проверен в игре.** На момент подготовки публикации карта Маяк
> закрыта для автора из-за игровой прогрессии, поэтому её нельзя было проверить
> в реальном рейде. Превью и данные Маяка сгенерированы из встроенных данных,
> а не сняты с игры. Считайте выравнивание карты, выходы, опасности и квесты
> Маяка **непроверенными**, пока карта не будет открыта и проверена в рейде.

- **Белая стрелка в центре** — вы. Карта поворачивается так, чтобы взгляд
  смотрел вверх экрана.
- **Выходы**:
  - зелёный — Scav;
  - синий — PMC;
  - жёлтый — общий;
  - фиолетовый с `T|` — транзит на другую локацию.
- **Этажи**: `^` / `v` перед именем — выход на другом этаже; он рисуется
  тусклее.
- **Опасности**:
  - красный контур/точка — минное поле;
  - оранжевый контур — снайперская зона;
  - золотой `+` — ловушка/клеймор.
- **Квесты** (F4): цветные зоны и точки, подписи цветом квеста; ромб `K|` —
  дверь, которую открывает ключ отслеживаемого квеста.
- **Фарм** (F3): золотая линия маршрута, круги кластеров лута, HUD с целью и
  расстоянием до выхода.
- Внизу слева: карта, этаж и координаты `X,Y,Z`.

Переключатели выходов и опасностей — в `F9`.

## 6. Настройки (F9)

- **EFT screenshots folder** — папка скриншотов. **Browse…** — выбрать,
  **Apply** — сохранить и перезапустить watcher, **Close** — закрыть панель.
- **PMC / Scav / Shrd** — какие выходы показывать.
- **Hazards** — мины, снайперские зоны, ловушки.
- **Manual pick** — ручной выбор карты; список карт появляется ниже.
  Повторный клик по выбранной карте снимает выбор.
- **Quests (F4)** — открыть панель квестов. Недоступна при активном фарме.
- **Farm (F3)** — открыть панель фарма.
- **Prices (F2)** — открыть панель цен.
- **Ignore floors** — показывать плоскую совмещённую карту вместо этажей.
- **Lang: EN/RU** — язык интерфейса (сохраняется).
- **debug: on/off** — подробный лог `tarkymappy.log`.
- Зелёная **?** — FAQ; красная **X** — выход; шестерёнка справа — вернуться в
  настройки с любой панели; уголок в правом нижнем углу — ресайз; верхняя
  полоса — перетаскивание окна.

Размер окна по умолчанию 400×400, минимум 260×260. Окно всегда поверх других,
прозрачное и не перехватывает клики, пока панель закрыта.

## 7. Квесты (F4)

1. Откройте `F4`.
2. По умолчанию показаны **отслеживаемые** квесты («Moi»).
3. Кнопка **All (N)** показывает все квесты текущей карты.
4. Галочка в строке — включить/выключить трекинг.
5. Клик по строке — подсказки: цели, нужные ключи, этаж, ссылка на wiki.
6. Фильтр фракции: **Any / BEAR / USEC**.
7. **Browse…** — папка `Logs` игры. Если она указана, квесты, взятые в игре,
   добавляются автоматически (`[AUTO]`), а карта определяется по логу.
8. **Scan hist** — разовый проход по последним сессиям логов: все квесты
   «quest started» из истории попадут в отслеживаемые.

Квесты с точками на нескольких картах имеют разный цвет на каждой карте —
это нормально: цвет привязан к паре «карта + квест», чтобы не было совпадений
внутри одной карты.

Ключи: если в открытых данных нет координат спавна ключа, приложение рисует
ромб двери, которую этот ключ открывает, и подпись `K|имя ключа`. Чужой этаж —
тусклее со стрелкой.

---

## 8. Фарм (F3)

1. Откройте `F3`.
2. Выберите категории лута: техника, медицина, продажа, оружие, дорогой тех.
3. Слайдер **Points** — максимум точек маршрута (5–35).
4. **Generate** — построить маршрут от текущей позиции.
5. **New from here** — перестроить маршрут, исключив уже посещённые точки.
6. **Reset** — выключить фарм.
7. Кнопка выхода — переключение выхода; `auto` выбирает самый дальний
   доступный выход.

Маршрут — по прямой: в открытых данных нет navmesh, поэтому линии не обходят
стены. Это подсказка направления, а не готовый навигатор.

При активном фарме квестовые маркеры скрыты, а панель квестов заблокирована —
один режим за раз.

---

## 9. Цены (F2)

- Вкладки **PvP** (`regular`) и **PvE** (`pve`).
- Показан топ предметов по цене за один слот инвентаря.
- В шапке — дата снимка цен.
- Данные лежат в `prices\prices.json` рядом с exe и перечитываются при каждом
  открытии `F2`.
- Обновление без пересборки:

```powershell
python prices\update_prices.py
```

Скрипт использует публичный API `tarkov.dev`; если GraphQL недоступен,
переключается на статические снапшоты `json.tarkov.dev`. Нужен интернет
только на время обновления.

Если `prices\prices.json` отсутствует или повреждён, приложение не падает:
панель покажет подсказку, а ошибка попадёт в лог.

## 10. Логи, конфиг и сброс

- Конфиг: `%AppData%\TarkyMappy\config.json`.
- Лог: `tarkymappy.log` рядом с exe.
- Для сброса настроек закройте приложение и удалите `config.json`.
- Папка логов EFT задаётся в `F4` или `F9`; пустая папка = ручной режим
  квестов.
- `debug: on` включает подробный лог; `debug: off` — обычный.

## 11. Сборка из исходников

Нужен **Go 1.27+**. Для обновления карт — ImageMagick, для цен — Python.

### Вариант 1: интерактивные помощники

- `build_ru.bat` — русский интерфейс;
- `build_en.bat` — английский интерфейс.

Скрипт проверяет файлы, Go, цены, запускает `go test`, `go vet`, `gofmt`,
собирает `dist\TarkyMappy.exe`, копирует `prices\` и документацию, при желании
делает `TarkyMappy-win64.zip`.

Быстрый неинтерактивный прогон (для проверки):

```powershell
build_en.bat /auto
build_ru.bat /auto
```

### Вариант 2: вручную

```powershell
go mod download
go test ./...
go vet ./...
go build -trimpath -ldflags="-s -w -H=windowsgui" -o dist\TarkyMappy.exe .
```

После сборки положите рядом с exe папку `prices`:

```
dist\
  TarkyMappy.exe
  prices\
    prices.json
    update_prices.py
```

Иконка уже вшита в `rsrc_windows_amd64.syso`; `icon64.png` нужен для иконки
окна через `go:embed`.

### Перегенерация карт (dev-time)

```powershell
powershell -File tools\make_maps.ps1 -Force
```

Если `magick.exe` не в `PATH`:

```powershell
powershell -File tools\make_maps.ps1 -Force -Magick 'C:\Program Files\ImageMagick-7.1.2-Q16-HDRI\magick.exe'
```

### Обновление данных (dev-time)

Скачайте снапшоты в `%TEMP%` по таблице из `UPDATING.md`, затем:

```powershell
powershell -File tools\update_data.ps1
go test ./...
```

## 12. Известные ограничения

- Customs и Reserve частично пересекаются по bounds: без истории рейдов
  автоопределение может ошибиться. Решение: `F10`, ручной выбор, папка логов.
- Маршрут фарма — прямые линии, без обхода стен.
- Этажи определяются по высоте `Y`; на нестандартных позициях возможен
  ручной выбор `PageUp` / `PageDown`.
- Подземные этажи некоторых карт почти пустые в исходном SVG; приложение
  подкладывает наземный слой полупрозрачно.
- Часть строк может остаться на английском, если перевода нет в
  `data/loc_ru.json` — это штатный fallback.
- Данные — снимок на дату из `data/meta.json`. После патча игры обновите
  данные по `UPDATING.md`.
- На карте Lighthouse используется кастомный арт reemr/re3mr.com; он не
  перерисовывается из SVG и обновляется отдельно.
- **Маяк не проверен в живом рейде.** Карта закрыта для автора по прогрессии;
  проверка была только по встроенным данным и превью. После открытия карты
  стоит вручную сверить положение игрока, выходы, опасности и квестовые точки.

## 13. Частые проблемы

| Проблема | Что сделать |
|---|---|
| Оверлей не виден | Нажмите `F7`; проверьте, что игра в Borderless; окно должно быть поверх. |
| Нет точки игрока | Сделайте первый скриншот в рейде; проверьте папку скриншотов в `F9`. |
| Не та карта | `F10` или ручной выбор в `F9`; укажите папку логов EFT в `F4`. |
| Не видно выходов | Проверьте галочки PMC/Scav/Shrd в `F9`; некоторые выходы на другом этаже. |
| F2 пустая | Нет `prices\prices.json`; запустите `python prices\update_prices.py`. |
| Не обновляются квесты | Укажите папку `Logs` в `F4`; нажмите `Scan hist`; проверьте лог. |
| Окно не двигается | Тяните за верхнюю полосу; ресайз — за правый нижний угол. |
| Антивирус/SmartScreen | Разблокируйте exe в свойствах файла; сборка из исходников тоже вариант. |
| Нужно сбросить настройки | Удалите `%AppData%\TarkyMappy\config.json` при закрытом приложении. |

## 14. Приватность и безопасность

- В обычной работе приложение **не использует сеть**, не читает память игры,
  не внедряется в процесс и не перехватывает трафик.
- Оно читает **имена файлов скриншотов** и, если указано, **текстовые логи
  EFT** — локально.
- Содержимое скриншотов не анализируется.
- Сеть используется только скриптом `prices\update_prices.py` при обновлении
  цен.
- Конфиг и лог остаются на вашем компьютере; телеметрии нет.

Проект неофициальный и не связан с Battlestate Games. Проверяйте правила игры
и используйте на свой риск.

## 15. Удаление

1. Нажмите `F8`.
2. Удалите папку с `TarkyMappy.exe` и `prices`.
3. При желании удалите `%AppData%\TarkyMappy\config.json` и `tarkymappy.log`.
